## 🎯 System Overview

ZipRun Ops Center provides logistics coordinators with a single-pane-of-glass dispatch dashboard. It connects directly with the **ZipRun AI Reassignment Engine** to handle live driver disruptions, visualize capacity thresholds, and review automated AI reassignment proposals before delivery SLAs are breached.

```
                               ┌────────────────────────────────────────┐
                               │       ZipRun Ops Center Dashboard      │
                               │     (shadcn White & Light Blue)        │
                               └───────┬────────────────────────┬───────┘
                                       │                        │
                   5-Second Poll (REST)│                        │ SSE Stream
                                       ▼                        ▼
                               ┌────────────────────────────────────────┐
                               │    ZipRun AI Reassignment Engine       │
                               │        (Spring Boot 3.3 Backend)       │
                               └────────────────────────────────────────┘
```

## 🎨 UI Features & Design System

Styled with an enterprise **shadcn-inspired White & Light Blue Theme** featuring high-contrast slate typography (`#0f172a`), sky blue focus accents (`#0284c7`), and glassmorphism elements.

### 1. 🚴 Fleet Telemetry & Roster (`AgentRoster.tsx`)
- Displays all active delivery agents across operational zones (`Zone-A`, `Zone-B`, `Zone-C`).
- **Load Capacity Bars**: Color-coded capacity indicators (Green `<50%`, Amber `50-80%`, Red `>80%`).
- **1-Click Status Toggling**: Click any status pill to flip an agent (`AVAILABLE` ↔ `OFFLINE`). Firing `OFFLINE` immediately triggers the backend's asynchronous agentic re-planning loop.

### 2. 🤖 AI Re-planning Queue (`SuggestionCard.tsx`)
- **🔴 Auto Re-plan Badge**: Visually demarcates suggestions auto-generated by the agentic loop from manual on-demand suggestions.
- **AI Confidence Gauge**: High-contrast progress bar reflecting model confidence score (`0.0 – 1.0`).
- **Verbatim AI Reasoning**: Full markdown chain-of-thought rationale explaining why a specific agent was selected.
- **One-Click Resolution**: `✓ Accept` instantly reassigns the order and shifts capacity; `✕ Reject` dismisses the recommendation.

### 3. 📦 Full Dispatch Kanban Board (`OrderBoard.tsx`) — *UI Ceiling (+8 Pts)*
- 4 Kanban columns tracking order lifecycle:
  1. `ASSIGNED` — Pre-assigned active deliveries.
  2. `PENDING REASSIGNMENT` — Orders stranded due to driver failure.
  3. `REASSIGNED` — Orders routed to replacement drivers.
  4. `DELIVERED` — Completed orders.
- **Real-Time SLA Countdown Clocks**:
  - 🟢 **Safe** (`> 1 hour left`)
  - 🟡 **Warning** (`< 1 hour left`)
  - 🔴 **Breach Alert** (`< 0 minutes` — animated pulse indicator)
- Displays parcel weight class (`LIGHT` vs `HEAVY`) and pickup/dropoff routing zones.

### 4. ⚡ Live AI Reasoning Terminal (`SsePanel.tsx`) — *SSE Bonus (+5 Pts)*
- Slide-up bottom terminal that connects directly to `GET /api/orders/{id}/suggest/stream`.
- Renders live token-by-token LLM thought emission with an animated typing cursor and pulsing thinking indicator.

### 5. 🔔 Notification System (`Toast.tsx`)
- Non-blocking floating status alerts for fleet changes, suggestion acceptances, and background loop triggers.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/PPC2001/ziprun-ops-center.git
cd ziprun-ops-center

# Install dependencies
npm install
```

### 2. Environment Configuration
Create a `.env` file in the `frontend/` directory (or copy from `.env.example`):

```bash
cp .env.example .env
```

```env
# Point to your running backend API
VITE_API_URL=http://localhost:8080/api
```

### 3. Run Development Server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 4. Production Build
```bash
npm run build
```
Creates an optimized production bundle in the `dist/` directory.

## ☁️ Deployment on Vercel

The application includes a pre-configured [`vercel.json`](file:///C:/Users/Pratik/Desktop/Projects/Zycus/frontend/vercel.json) supporting Single Page Application (SPA) HTML5 pushState routing:

```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite",
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
```

### Deploying via Vercel CLI:
```bash
# Deploy to preview
npx vercel

# Deploy directly to production
npx vercel --prod
```

### Deploying via GitHub:
1. Connect [`https://github.com/PPC2001/ziprun-ops-center`](https://github.com/PPC2001/ziprun-ops-center) on your Vercel Dashboard.
2. Under **Project Settings > Environment Variables**, add `VITE_API_URL` pointing to your deployed backend URL.
3. Every push to `master` triggers an automatic zero-downtime deployment.
